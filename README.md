# Space-Saving 網路流量重現實驗

軟體定義網路及網路功能虛擬化課程專題。使用 Space-Saving 在有限的計數器預算下，從封包串流找出封包數最多的來源 IP。

## 研究問題

固定輸出 Top-10 時，計數器數量（16、32、64、128）和流量集中程度如何影響 Top-10 召回率、封包數估計誤差與記憶體用量？

第一階段驗證更新規則和誤差界。若要重現原論文的圖表，先由全組選定圖表，對齊資料分布、參數和評估指標，再將來源 IP 實驗列為網路流量延伸。

## 三人分工

| 組員 | 負責範圍 | 交付物與完成條件 |
| --- | --- | --- |
| A（待填姓名） | **演算法與驗證。** 檢查 C++ 參考實作的授權與介面，建立可調整計數器數量的 Space-Saving 執行程式。驗證已追蹤項目加一、空位新增與滿表替換三種情況。 | `src/` 的程式、編譯與執行說明、小型測試資料及預期輸出。每筆結果包含來源 IP、估計次數、誤差上限。負責報告的演算法章節。 |
| B（待填姓名） | **資料與精確基準。** 建立流量分散與集中的可重現合成資料，保留亂數種子。整理選定的封包資料，以原始順序擷取來源 IP，並用完整計數產生真實 Top-10。 | `data/` 的資料來源和生成說明、`baseline/` 的精確計數工具與小型樣本。記錄資料筆數、不同 IP 數和分布設定。負責報告的資料與基準章節。 |

以上路徑是預定交付位置。全組共同決定重現目標，各自撰寫負責章節，最後交叉核對圖表和結論。

## 共用介面與評估方式

- **輸入**：UTF-8 純文字，每行一個來源 IP，保留原始順序。三人先用同一個小樣本確認介面。
- **排名**：固定取前 10 筆。次數相同時以 IP 字串順序決定排名，兩種方法使用相同規則。測試資料至少包含 10 個不同 IP。
- **Top-10 召回率**：估計名單和精確名單的交集大小除以 10。
- **封包數估計誤差**：對估計名單中的 IP，比較估計值與同一 IP 的精確次數，回報平均絕對誤差。漏掉的真實前十名由召回率反映。
- **記憶體**：記錄計數器預算與實際使用筆數。若量測尖峰記憶體，使用相同環境與方法，並與計數器筆數分開報告。

## 整合順序

1. **共同確認**：填上組員姓名，確認原論文要重現的圖表，並定下第一批測試資料。
2. **並行開發**：A 提供更新程式與手算測試，B 提供資料和精確排名，C 先用小樣本完成批次實驗框架。
3. **整合驗證**：三人核對小樣本結果與誤差界，再執行完整參數組合並整理報告。
